# ContextCue pitch notes

ContextCue helps international students in Singapore understand unfamiliar communication cues and practise clear, respectful responses.

Demo: situation → relevant context and uncertainty → write a reply → feedback → add context and retry.

Implemented: 12-card retrieval, source/provenance display, Gemini adapter, reference fallback mode, response practice, input validation and explicit provider errors.

Data: research-informed synthetic scenarios awaiting student review. Peer-sourced context is the intended core; do not say these are peer-verified or that student tests have happened.

AI role: adapt relevant context to the actual conversation and coach the user's reply. Without credentials, reference mode demonstrates retrieval and self-reflection only.

Validation evidence: report automated checks separately from real student observations. Do not claim measured learning gains. A live Gemini demo is only verified after an actual successful provider request.
